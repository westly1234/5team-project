5team‑Project – AI‑Powered Wellness Platform

5team‑Project는 Django로 구축된 종합 웰니스 플랫폼으로, 피트니스 추적, 식단 분석, 음악 추천, 헬스장 검색, 쇼핑 및 인터랙티브 AI 건강 코치를 모두 한곳에 담았습니다. 폭넓은 업적 시스템을 통해 건강한 습관을 게임처럼 즐길 수 있게 해주고, 최신 언어 모델로 개인화된 인사이트를 제공해 줘요.

핵심 기능

통합 회원 관리 시스템 – 회원가입, 로그인, 프로필 수정, 다국어(한국어/영어/스페인어) 지원, 이메일 인증과 비밀번호 재설정까지. 프로필에는 키, 몸무게, 목표 체중 등 건강 지표를 저장합니다.

업적 엔진 – 모듈 전반에 걸쳐 배지와 칭호를 부여하는 중앙 서비스. 첫 운동, 연속 기록, AI 대화, 식단 기록, 음악 탐색, 장소 검색, 체형 분석 등 다양한 성과를 축하합니다.

AI 챗봇 & 건강 코치 – LangChain과 FAISS, OpenAI 모델을 활용한 풍부한 대화형 에이전트로, 질문에 답하고, 운동/식단 조언을 제공하며, 업로드된 파일을 해석하고, 상품 추천을 하며, DALL‑E로 이미지를 생성합니다. 대화는 저장·요약되며 이름을 바꾸거나 삭제할 수 있어요.

식단 관리 – 식사 기록과 사진 업로드 기능을 제공하고, GPT‑4‑O로 영양 분석 및 하루/주간 섭취 요약을 수행합니다. 꾸준한 기록, 균형 잡힌 영양 등 다양한 업적을 달성할 수 있습니다.

루틴 생성기 – 근육 부위와 난이도를 기반으로 GPT가 맞춤형 운동 루틴을 만들어 주거나, 사용자가 직접 루틴을 설계할 수 있습니다. 세트/반복/중량을 포함해 수정 및 분석도 가능하며, 운동 기록을 통해 연속 기록을 추적합니다.

음악 추천 – 운동 종류, 기분, 장르를 고려해 GPT가 개인화된 YouTube 검색 키워드를 생성합니다. 좋아요/싫어요를 저장하고, 새로운 감정이나 운동을 탐색하며 음악 관련 업적을 획득하세요.

장소 찾기 – Kakao Map API를 이용해 근처 헬스장, 요가 스튜디오, 수영장 등을 검색할 수 있습니다. 검색 로그를 기반으로 카테고리 다양성, 시간대(야행성/주말)에 따른 업적이 잠금 해제됩니다.

스토어 & 체형 분석 – 건강 브랜드 리스트를 필터링, 즐겨찾기, 리뷰 작성까지. 목표(다이어트/근육)와 우선순위(비건/가격)에 따라 상품을 추천받고, 사진을 업로드해 AI‑기반 체형 분석과 패션·훈련 팁을 받을 수 있습니다. 브랜드 설명과 태그가 없으면 GPT가 자동 생성해 줍니다.

대시보드 & 건강 지표 – 중앙 서비스 페이지에서 최신 루틴과 오늘의 식단 요약을 확인하고, 지난 한 달간의 체중/근육/체지방 차트를 볼 수 있습니다. 계정, 식단, 건강 지표 등에서 데이터를 가져와 통합 제공합니다.

다국어 지원 – locale/과 locales/*.json 파일을 통해 한국어, 영어, 스페인어 번역을 제공합니다. 많은 프롬프트와 메시지가 사용자의 언어로 생성됩니다.

기술 스택

Backend: Django & Django REST Framework (Python 3.11), PostgreSQL(또는 개발용 SQLite), 캐싱용 Redis.

AI: 식단 분석, 음악 키워드, 운동 계획, 체형 조언, 챗봇 응답에 GPT‑4‑O 및 GPT‑4‑O‑Mini를 사용하며, 이미지 생성에는 DALL‑E를 활용합니다. RAG 구현을 위해 LangChain & FAISS를 사용합니다.

Front‑end: Bootstrap과 Tailwind CSS가 적용된 Django 템플릿, 차트와 AJAX 필터를 위한 JavaScript.

외부 API: Kakao Map(장소 검색), YouTube(음악 플레이리스트), Coupang(상품 추천), Mediapipe/OpenCV(옵션) 등을 사용합니다.

디렉토리 개요

각 기능은 자체 Django 앱에 담겨 있습니다. 아래 표는 주요 폴더와 책임을 요약합니다:

폴더	설명
Steam‑project/	Django 프로젝트 설정: settings.py, urls.py, WSGI/ASGI 엔트리 포인트 등.
accounts/	사용자 관리: 회원가입, 이메일 인증, 로그인/로그아웃, 프로필 수정, 비밀번호 재설정, 건강 설문. 프로필 완성도 및 계정 기념일에 대한 업적도 부여합니다.
achievements/	배지·칭호 정의와 전 플랫폼에 배포하는 중앙 서비스. 첫 루틴 생성, 연속 기록, AI 대화 횟수 등 모든 앱에서 업적 트리거를 제공합니다.
chatbot/	AI 건강 코치 구현. FAISS 벡터 스토어를 로드하고 LangChain으로 관련 문서를 검색하며 GPT 모델로 질문에 답하고 운동 요약을 작성합니다. Coupang API로 상품을 추천하고 DALL‑E로 이미지를 생성합니다. 대화 기록 및 업적 관리도 포함되어 있어요.
diet/	식사 기록과 분석을 담당합니다. 사용자가 식사를 기록하고 사진을 업로드하면 GPT가 영양 성분을 분석하고, 하루/주간 섭취량을 요약합니다. 연속 기록, 균형 잡힌 영양 섭취 등 업적을 제공합니다.
music/	개인화된 음악 추천 엔진. 운동 종류, 기분, 장르를 기반으로 GPT가 YouTube 검색 키워드를 생성합니다. 결과를 캐싱하고, 좋아요/싫어요 기록을 저장하며, 음악 관련 업적을 해금합니다.
place/	Kakao Map 기반 장소 검색 인터페이스를 제공. 각 검색을 기록하고 카테고리와 시간대를 카운팅해 ‘야행성’, ‘주말 전사’ 같은 업적을 잠금 해제합니다.
routine/	운동 루틴을 관리합니다. 사용자가 직접 루틴을 만들거나 GPT가 4–6개의 운동으로 구성된 루틴을 생성해줍니다. 루틴 수정, 삭제, 완료 기록, 연속 기록, AI 분석(번역 포함) 기능을 갖추고 있어요.
store/	건강 브랜드 이커머스 모듈. 필터링, 즐겨찾기, 리뷰 작성이 가능하고 목표와 우선순위에 따라 브랜드를 추천합니다. AI 기반 체형 분석과 브랜드 설명/태그 자동 생성 기능도 제공됩니다.
web/	사이트 전반의 뷰를 관리합니다: 홈, 회원가입, 서비스 대시보드, 문의 폼 등이 여기서 정의됩니다. 대시보드는 계정, 루틴, 식단, 건강 지표 데이터를 통합해 차트와 요약을 보여줍니다.
config/	추가 설정과 환경 변수 관리를 담당하는 모듈.
locale/ & locales/	한국어, 영어, 스페인어 번역을 위한 .po/.mo 및 JSON 파일.
media/	프로필 사진, 식사 사진, 체형 분석 이미지, 대화 이미지 등 사용자 업로드 파일.
staticfiles/	collectstatic으로 모은 정적 자산(JS, CSS, 이미지).
assets/	프론트엔드에서 사용하는 추가 정적 리소스.
설치 및 실행

레포 클론 후 의존성 설치:

git clone https://github.com/westly1234/5team-project.git
cd 5team-project
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt


.env 파일 생성 또는 환경 변수 설정:

# Django 설정
SECRET_KEY=your_secret_key
DEBUG=True
ALLOWED_HOSTS=*

# API 키
OPENAI_API_KEY=sk-...
YOUTUBE_API_KEY=...
KAKAO_MAP_API_KEY=...
COUPANG_ACCESS_KEY=...      # 상품 추천을 사용할 경우
COUPANG_SECRET_KEY=...


마이그레이션 및 관리자 계정 생성:

python manage.py migrate
python manage.py createsuperuser


정적 파일 수집(배포 시) 및 서버 실행:

python manage.py collectstatic
python manage.py runserver


웹 사이트는 http://localhost:8000/에서 접속할 수 있으며, 관리자 패널은 /admin/에 있습니다. 여기서 사용자, 업적 등 모델을 관리할 수 있어요.
